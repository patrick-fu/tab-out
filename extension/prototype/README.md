# Tab Out 界面原型

本分支回答：标签很多时，怎样的信息层级、布局和搜索方式更舒服？目前尚未选定方案，不进入生产分支。

运行：在本仓库根目录执行 `python3 -m http.server 8767 --bind 127.0.0.1`。

- A 静谧工作台：`http://127.0.0.1:8767/extension/index.html?variant=A`，左侧筛选、中间紧凑列表、右侧详情和稍后阅读。
- B 纸上索引：`http://127.0.0.1:8767/extension/index.html?variant=B`，浅色索引卡片、较完整标题、抽屉式保存区。
- C 快捷启动器：`http://127.0.0.1:8767/extension/index.html?variant=C`，深色优先、搜索和键盘操作为中心、单列分组结果。

底栏支持切换方案、深浅色与重置；左右键切换方案，输入框内不拦截；`/` 聚焦搜索，↑↓选择，Enter 仅模拟跳转，Esc 清空。切换保留演示状态，刷新恢复虚拟初始数据。

全部使用相同的 24 个虚拟标签和保存/归档数据，包含重复、长标题、3个窗口和localhost端口。不调用 Chrome API、不持久化、不访问外部资源。请通过HTTP启动（ES Module不保证file协议可运行），不要将本分支加载为真实扩展。

AGY 使用 gemini-3.8-flash-high 生成三版主体；生成运行在12分钟期限触发超时，未返回完成报告。主agent随后实际检查和接手修正比较栏、390px窄屏、主题状态保留、稳定分组顺序、搜索输入转义、滚动恢复与副本数量提示。

验收：三版实际打开、搜索、虚拟关闭和保存、跨方案状态保留、键盘模拟跳转、Esc与重置、A/B窄屏无横向溢出，浏览器无已记录JS错误；JavaScript语法检查和git diff --check通过。未增加自动化测试，仍是可丢弃外观原型。
